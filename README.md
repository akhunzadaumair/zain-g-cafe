# ☕ Zain G Cafe

A modern, responsive cafe website designed to provide customers with a smooth and user-friendly digital experience.

## 🌐 Live Demo

https://zain-jeecafe.netlify.app/

## ✨ Features

- Modern and responsive cafe website
- Menu and food items showcase
- Customer-friendly ordering experience
- WhatsApp ordering integration
- Branch/location information
- Mobile, tablet and desktop responsive design
- Clean and modern user interface
- Fast and user-friendly navigation
- Interactive website sections

## 🛠️ Technologies

- TypeScript
- React / Vinext
- HTML5
- CSS
- JavaScript
- Responsive Web Design

## 📱 Responsive Design

The website is designed to work smoothly across:

- Desktop
- Laptop
- Tablet
- Mobile

## 🎯 Project Goal

The goal of this project was to create a modern online presence for Zain G Cafe and make it easier for customers to explore the cafe, view available items and place orders.
